# Chalani Isara Jayawardhana — Portfolio

A responsive personal portfolio built with HTML, CSS, and JavaScript and ready for **GitHub Pages**.

## Publish

1. Open your GitHub repository `https://github.com/cjishara/cjishara.github.io`.
2. Upload **all of the files and the `assets` folder** from this project to the repository's root (not inside an extra `chalani-portfolio` folder).
3. Commit the files to the `main` branch.
4. Open **Settings → Pages** and choose **Deploy from a branch**, `main`, `/(root)`; save.
5. Visit `https://cjishara.github.io` after deployment finishes.

## What to customize

- Update `index.html` with new projects and verified credentials as you gain experience.
- The email and GitHub URL come from your CV / account details. Home address and phone number are intentionally excluded for privacy.
- The hero portrait is an embedded image extracted from your uploaded CV. The other illustrations are original SVG artwork.
- `Chalani_Isara_Jayawardhana_CV.pdf` is the supplied CV; replace it if you update your CV.

All assets are local except Google Fonts (which gracefully falls back to system fonts if unavailable).
